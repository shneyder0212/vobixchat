VOBIXCHAT ANDROID

1. Esta carpeta es la base nativa Android para Firebase y llamadas entrantes.
2. Abrir la carpeta "android" con Android Studio.
3. Esperar que Android Studio sincronice Gradle.
4. Conectar el Samsung por USB y pulsar Run para instalar.

El archivo google-services.json ya corresponde a:
com.vobixchat.mobile

No copiar ni guardar aquí la clave privada del servidor Firebase.
Esa clave se queda únicamente en Render como:
FIREBASE_SERVICE_ACCOUNT_JSON
